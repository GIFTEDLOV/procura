# Procura product scope

Procura is an on-chain procurement workflow for buyers, suppliers, and
reviewers. The current release specifically resolves the steward finding by
making the live create tender, bid, evidence, and delivery actions functional
against the verified Studionet contract and shared method schema.

The qualifying workflow exercised tender creation, requirement freeze and
funding, bid submission and evidence, adjudication, award and supplier
acceptance, delivery, and delivery evidence. It used a real pinned public
package manifest as evidence. No unrelated settlement, payout, or dispute
activity was included.

The rest of the product's demo surfaces remain explicitly labeled as
CONTROLLED DEMO; historical deployment details remain read-only. Current LIVE
state is sourced from Studionet only. See [LIVE proofs](LIVE_PROOFS.md) and
[release provenance](../evidence/release-provenance.json).
