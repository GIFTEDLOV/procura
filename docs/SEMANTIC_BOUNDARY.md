# Semantic boundary

Semantic adjudication can answer only whether authenticated supplier evidence materially satisfies a frozen requirement, whether an equivalence claim is acceptable under frozen rules, whether evidence materially conflicts, and whether delivered goods match the awarded specification.

It cannot choose winners, set prices, determine amounts, select recipients, establish deadlines, identify wallets, or authorize state transitions. The contract derives canonical enum verdicts from strict vectors and keeps raw model prose out of the primary UX.
